MJ BTS GAMING
================

A fan-style BTS member gaming website concept with the name MJ.

Files:
- index.html
- style.css
- script.js

How to use:
1. Keep all three files in the same folder.
2. Open index.html in Chrome/Edge.
3. Search or filter the BTS member cards.
4. Upload the folder to GitHub Pages, Cloudflare Pages, or another static host.

Note:
This is a fan-made concept and is not affiliated with or endorsed by BTS, BIGHIT MUSIC, HYBE, or their representatives.
